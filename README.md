My personal developer portfolio: AI tools that show their evidence and keep humans in the loop, plus the full-stack products around them.

**Live site:** [aayushbuilds.vercel.app](https://aayushbuilds.vercel.app)

## What's inside

- Boot-screen intro and a self-typing terminal hero
- Dark theme by default, with a light option
- A case-study page for every project
- A GitHub section that refreshes hourly
- Generated Open Graph images, sitemap and structured data

## Built with

Next.js 15 · React 19 · Tailwind CSS · Framer Motion · Lucide React · deployed on Vercel

## Run it locally

You need Node.js 18.18 or newer.

```bash
git clone https://github.com/aayush-as69/aayushbuilds.git
cd aayushbuilds
npm install
npm run dev
```

Then open <http://localhost:3000>.

Optionally, copy `.env.example` to `.env.local` to set `NEXT_PUBLIC_SITE_URL` (your site's public address) and `GITHUB_TOKEN` (raises the GitHub API rate limit).

## Edit the content

Everything on the site comes from two files:

- `data/site.js`: profile, about, skills and experience
- `data/projects.js`: projects and case studies
